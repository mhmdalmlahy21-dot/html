# Leon Template — صفحة الهبوط (Landing Page)

مشروع صفحة ويب مبنية بلغة **HTML** لتطبيق قالب **Leon** كما تم شرحه في المحاضرة، مع تنظيم الملفات في مجلدات وإرفاق تعليقات (`comments`) داخل الكود لتوضيح كل جزئية.

## هيكلة المجلدات والملفات
- `index.html`: الصفحة الرئيسية للمشروع وتحتوي على بنية الصفحة مقسمة وموضحة بالتعليقات (`<!-- ... -->`).
- `css/`: يحتوي على ملف التنسيق الرئيسي `main.css`.
- `html/`: مجلد مخصص لصفحات HTML الإضافية.
- `imeges/`: يحتوي على الصور المستخدمة في الصفحة مثل `logo.png` و`proj1.png` و`proj2.png` و`proj3.png` و`temp.png`.
- `webfonts/`: مجلد الخطوط والأيقونات.
- `README.md`: ملف توثيقي يشرح فكرة المشروع وأقسام الكود وطريقة التشغيل.

## شرح أجزاء الكود في `index.html`
1. **الرأس والتعريفات (`<head>`):**
  - تحديد الترميز (`UTF-8`)، التوافق مع المتصفحات، عنوان الصفحة (`Leon Template`)، وإعدادات `viewport`.
  - ربط ملف التنسيق الخارجي `css/main.css` وخطوط Google Fonts ومكتبة أيقونات Font Awesome.
2. **رأس الصفحة والتنقل (`<header>` - `#header`):**
  - يعرض شعار الموقع (`imeges/logo.png`)، أيقونة القائمة (`fa-bars-staggered`)، وقائمة تنقل (`<ul>`) تربط بأقسام الصفحة (`#features`، `#services`، `#portfolio`، `#about`).
3. **قسم البداية (`#landing`):**
  - مخصص لعرض واجهة البداية/الهبوط الخاصة بالقالب.
4. **قسم المزايا (`#features`):**
  - يعرض ثلاث بطاقات مزايا (`.feat`) مزودة بأيقونات Font Awesome وعناوين `<h3>` ونصوص وصفية `<p>`.
5. **قسم الخدمات (`#services`):**
  - يحتوي على العنوان الخاص (`.special-heading`) بعنوان `services`، ثم شبكة أعمدة (`.col`) تضم خدمات (`.serv`) مثل: `graphic design`، `UI / UX`، `web design`، `web development`، بالإضافة إلى صورة الشعار.
6. **قسم الأعمال / المعرض (`#portfolio`):**
  - يعرض عنوان `portfolio` ومجموعة مشاريع (`.full-project`) تحتوي كل منها على صورة (`proj1.png`، `proj2.png`، `proj3.png`)، عنوان `<h4>`، ووصف `<p>`.
7. **قسم من نحن (`#About`):**
  - يعرض عنوان `About` ومحتوى تعريفي (`.about-content`) يضم صورة (`imeges/temp.png`) وفقرات نصية فاصلة بينها `<hr>`.
8. **قسم التواصل (`#contact`):**
  - يعرض عنوان `contact`، بريد التواصل (`leon@gmail.com`)، وقسم الروابط الاجتماعية (`.social`) لأيقونات Google وFacebook وTwitter.

## تنظيم الكود والتعليقات
- تم تقسيم أقسام الكود بتعليقات (`<!-- start ... -->` و`<!-- end ... -->`) لسهولة التتبع والقراءة.
